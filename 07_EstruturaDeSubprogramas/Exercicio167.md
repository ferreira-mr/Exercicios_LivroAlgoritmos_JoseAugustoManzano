# 📝 Exercício 167: Verificador de Paridade com Função

## 📖 Descrição
Escreva um programa que leia um número inteiro e utilize uma função lógica para verificar se ele é par.

## 🚶 Passo a Passo
1. Entrada de Dados:
   - Solicite um número inteiro.
2. Processamento:
   - Crie a função e_par(n) retornando verdadeiro se n % 2 for 0, e falso caso contrário.
3. Saída de Dados:
   - Apresente 'par' ou 'impar'.
   
## 🧪 Exemplos
- Exemplo 1:
  - Entrada: 42
  - Saída: par
   
## 💻 Exemplo em Pseudocódigo
```plaintext
funcao e_par(n)
  retorne n % 2 == 0
fim_funcao
// Principal
SE e_par(num) ENTÃO exibir "par" SENÃO exibir "impar" FIM SE
```

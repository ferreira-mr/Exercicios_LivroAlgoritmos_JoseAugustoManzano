# 📝 Exercício 169: Fatorial com Função

## 📖 Descrição
Escreva um programa que use uma função para calcular e retornar o fatorial de um número inteiro positivo.

## 🚶 Passo a Passo
1. Entrada de Dados:
   - Solicite um número inteiro positivo.
2. Processamento:
   - Crie a função fatorial(n). Ela deve conter um laço multiplicando os valores de 1 a n e retornar o resultado.
3. Saída de Dados:
   - Apresente o fatorial calculado.
   
## 🧪 Exemplos
- Exemplo 1:
  - Entrada: 5
  - Saída: 120
   
## 💻 Exemplo em Pseudocódigo
```plaintext
funcao fatorial(n)
  fat = 1
  PARA i DE 1 ATE n FAÇA
    fat = fat * i
  FIM PARA
  retorne fat
fim_funcao
```
